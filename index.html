        SSH session

        Azure Bastion

        Uses az network bastion tunnel: needs the Azure CLI (az login, az extension add -n bastion) and a Bastion Standard or Premium SKU with Native client support enabled. Find the VM resource ID under the VM's Properties in the Azure portal.

        The terminal uses your system OpenSSH client (so ~/.ssh/config, agents and known_hosts work) and types the saved password at the login prompt. Remembered passwords are kept in the OS credential store (Windows Credential Manager), never in Moxie's config files.
