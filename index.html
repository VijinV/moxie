        ✦ What's New in Moxie
        v0.3.3
        
      
          
      
          
        
        
      
          
      
          
      
          

        
          
          
          v0.3.3 — Current
          
          
          
            🔌
            
          
              
          Service versions in the monitor
          
              
          The activity monitor now shows a Services column listing every installed runtime and service (nginx, PHP, Node.js, npm, Python, MySQL, PostgreSQL, Redis, Docker, Java, Go, Ruby, pm2) with its version number — both for this PC and for SSH servers.
          
            
          
          
          
          
          
            🪜
            
          
              
          Jump host passwords work correctly
          
              
          Fixed auto-login through jump hosts when the jump host and the target server have different passwords. The app now types each password to the right prompt instead of using the same one twice.
          
            
          
          
          
        
          

        
          
          
          v0.3.2
          
          
          
            🏷
            
          
              
          Session colours, icons and tags
          
              
          Give each server a colour and an icon (preset or any emoji) and tag it. The sidebar and its tabs show them; type #prod in the filter to list only sessions tagged prod.
          
            
          
          
          
          
          
            ⇤
            
          
              
          Collapsible sidebar
          
              
          Collapse the sidebar to an icon rail (« or Ctrl+Shift+L). Click an icon to slide the full sidebar out over the terminal.
          
            
          
          
          
          
          
            ⚠
            
          
              
          Deletes always ask
          
              
          Any command the AI wants to run that deletes something (rm, del, Remove-Item, find -delete, docker rm, DELETE FROM…) needs your OK, in every mode, including Run ▶ on a suggested command.
          
            
          
          
          
          
          
            ✓
            
          
              
          Thinner scrollbars
          
              
          Every panel uses a thin, dark scrollbar; the chat log no longer runs under its buttons.
          
            
          
          
          
        
          

        
          
          
          v0.3.1
          
          
          
            ✎
            
          
              
          Built-in editor
          
              
          Edit files inside Moxie, like MobaTextEditor: double-click a file in the SFTP panel, Ctrl+click a path in the terminal, or open one from this PC. Syntax highlighting, tabs, find & replace, and Ctrl+S saves straight back to the server. It won't overwrite a file that changed on the server since you opened it. Ctrl+Shift+O switches between editor and terminal.
          
            
          
          
          
          
          
            ⬆
            
          
              
          Update notice
          
              
          When a new version is out, a card offers Update now, What's new (with the release notes) or Later, and What's New gets a dot.
          
            
          
          
          
          
          
            ⤢
            
          
              
          Chat full view
          
              
          Hide the terminal and give the chat the whole window: ⤢ in the Assistant header or Ctrl+Shift+M. Terminals keep running underneath, so the agent can still run commands.
          
            
          
          
          
          
          
            ▣
            
          
              
          One activity monitor, more server details
          
              
          The monitor now shows disks, uptime, OS and per-core CPU, for this PC and for servers. On SSH tabs it reuses the SFTP connection, so it works through jump hosts and Azure Bastion. It replaces the SFTP panel's Server tab.
          
            
          
          
          
          
          
            ⌂
            
          
              
          Cleaner SFTP toolbar
          
              
          Consistent icons for parent folder, home, refresh, new folder and upload.
          
            
          
          
          
          
          
            ✓
            
          
              
          Fixes
          
              
          Long hints in the sidebar wrap instead of scrolling sideways. Process names in the monitor are escaped, so a server can't inject markup.
          
            
          
          
          
        
          

        
          
          
          v0.3.0
          
          
          
            ✦
            
          
              
          AI agent with tools
          
              
          With the Claude or OpenAI API the assistant runs commands, reads files and lists folders itself (on the server for SSH tabs) until the task is done. Destructive commands always ask first.
          
            
          
          
          
          
          
            💬
            
          
              
          One chat per SSH session
          
              
          Each SSH session keeps its own chat. Plus full-text chat search, 📝 session summaries and 🔎 natural-language log search.
          
            
          
          
          
          
          
            ▣
            
          
              
          Activity monitor
          
              
          Live CPU, memory, network and process stats in a resizable bottom panel, for this PC or the server on SSH tabs. The SFTP panel also has a Server dashboard.
          
            
          
          
          
          
          
            ⊞
            
          
              
          Terminal upgrades
          
              
          Split right/down icons, find (Ctrl+F), foldable command output, Ctrl+click links and paths, broadcast typing, themes and fonts, workspace restore.
          
            
          
          
          
          
          
            ⇩
            
          
              
          Sessions
          
              
          Folders, import from ssh config / MobaXterm / PuTTY, jump hosts in SFTP, RDP and VNC sessions.
          
            
          
          
          
          
          
            ❏
            
          
              
          Snippets & workflows
          
              
          Saved commands with {{placeholders}}; workflows stop at the first failure. Press Ctrl+/ for all shortcuts.
          
            
          
          
          
          
          
            🔑
            
          
              
          Keys in the keychain
          
              
          AI API keys are kept in Windows Credential Manager instead of the settings file.
          
            
          
          
          
        
          

        
          
          
          v0.2.0
          
          
          
            ⬆
            
          
              
          Auto-update
          
              
          Signed updates delivered over GitHub Releases. Moxie checks in the background and shows a pill when a new version is ready.
          
            
          
          
          
          
          
            🕘
            
          
              
          Chat history
          
              
          Chats are saved automatically and can be continued later.
          
            
          
          
          
          
          
            ✎
            
          
              
          Edit & auto-upload
          
              
          Open a remote file in your editor; every save uploads it back.
          
            
          
          
          
          
          
            ⚠
            
          
              
          Error detection
          
              
          Failed commands get an Explain & fix chip; server-aware AI and autocomplete.
