The terminal that knows your servers

Moxie is a fast desktop terminal and SSH/SFTP client with an AI agent built in. It runs commands, reads files and explains errors on the machine you're connected to, and always asks before it deletes anything.

Everything in one window

Terminal, SSH client, file manager and editor

A MobaXterm-style workspace with a modern terminal inside. No juggling PuTTY, WinSCP and a text editor.

▤

Command blocks

Every command gets a green or red bar with its exit code. Click to copy output, fold it, re-run it or jump between commands with Ctrl+Shift+↑↓.

◫

Tabs & split panes

Up to four panes per tab, nested freely. Broadcast typing sends one command to every pane or every open terminal.

⇄

SSH sessions

Saved sessions in folders with colours, icons and tags. Jump hosts, port forwards, Azure Bastion, RDP and VNC. Import from ~/.ssh/config, MobaXterm and PuTTY.

🗂

SFTP panel

Browse next to every SSH tab, drag and drop files and folders, rename, delete. Works through jump hosts too.

✎

Built-in editor

Open remote files with syntax highlighting, tabs and find & replace. Ctrl+S saves straight back and never overwrites a file that changed on the server without asking.

▣

Server monitor

CPU per core, load, memory, disks, network and top processes for your PC or the server. A Services column detects nginx, PHP, Node, MySQL, Redis, Docker and more.

⇥

Autocomplete

Flags and subcommands for common tools, file names on the server over SFTP, history, plus grey inline suggestions from history and AI.

⌘

Snippets & workflows

Save commands with {{name:default}} placeholders. Workflows run line by line and stop at the first failure.

🎨

Yours to tune

Eight colour schemes, fonts and cursor styles. Tabs, splits and SSH sessions reopen when you start Moxie.

AI agent

An assistant that does the work, not just the talking

Moxie tells the assistant which OS, shell, user, host and folder you're in. It runs commands, reads files and lists folders on the server, then keeps going until the task is done.

  • Explain & fix. A failed command gets a chip that sends exactly that command and its output to the AI.
  • Ask bar. Press Ctrl+K and describe what you want in plain language.
  • One chat per server. Each SSH session keeps its own searchable history.
  • Summarize & search logs. Get a handoff summary of a session, or describe what to look for and it searches logs read-only.
⚠Deletes always ask. rm, docker rm, DELETE FROM, git push --force, DROP TABLE, reboot and similar need your OK in every mode, including Auto-run.
